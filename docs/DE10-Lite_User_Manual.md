# DE10-Lite User Manual — provenance

`DE10-Lite_User_Manual.pdf` in this directory is Terasic's official user manual for
the board, retrieved 2026-08-09.

- **Source:** [faculty-web.msoe.edu mirror](https://faculty-web.msoe.edu/johnsontimoj/Common/FILES/DE10_Lite_User_Manual.pdf)
  — a university mirror of the same file Intel and Mouser host; those two were
  unreachable from this network at fetch time. Internal PDF metadata
  (`CreationDate: 2017-01-24`) matches the "January 24, 2017" edition indexed
  elsewhere, including Intel's own FPGA University Program FTP archive
  (`ftp.intel.com/.../Boards/DE10-Lite/DE10_Lite_User_Manual.pdf`) and
  [Mouser's datasheet mirror](https://www.mouser.com/datasheet/2/598/DE10-Lite_User_Manual-1100361.pdf) —
  same publisher, same content, different host.
- **Publisher:** Terasic Technologies, for the MAX 10 `10M50DAF484C7G` DE10-Lite board.
- **74 pages**, covers: board layout and connectors, power-up, the System Builder
  tool, full pin assignment tables for every header (GPIO, VGA, ADC, Arduino,
  accelerometer), and the bundled demonstration projects.
- Not modified from the source file.

See [`../board/README.md`](../board/README.md) for this project's own bring-up
notes and hardware corrections (the board is a DE10-**Lite**, not a DE10-Nano).
